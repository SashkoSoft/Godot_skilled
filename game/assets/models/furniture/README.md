## Единое правило подвижных узлов (все наборы)

У каждого подвижного узла в glb есть extras: `open_sign` (±1) и `anim` (hinge/flap/drawer/slide). Для `hinge`: поворот узла
на `open_sign × 90°` вокруг его вертикали (Y Godot) уводит полотно к ЛИЦУ модели (−Z Godot). Проверка:
`blender -b --factory-startup --python check_open_dir.py -- <файлы.glb>` → OPEN_DIR_RESULT OK.
