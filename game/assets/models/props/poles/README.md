# Опоры для проводов и фонари (СССР)

По фото с Wikimedia Commons (улицы Электростали, Ефремова, Шатурского района): стойки СВ-95 с 4 ярусами
стальных уголков-траверс и фарфоровыми изоляторами ТФ-20, фонарь «кобра» на гнутом трубчатом кронштейне,
угловая опора с подкосом, деревянная опора на ж/б пасынке с проволочными бандажами, стальная мачта с двумя «кобрами».

| Файл | Что | Высота | Треуг. LOD0/1/2 | Точек проводов |
|---|---|---|---|---|
| `pole_sv95` | ж/б стойка СВ-95 | 7.5 м | 2710 / 1814 / 1414 | 8 |
| `pole_sv95_lamp` | то же + «кобра» | 8.8 м | 3602 / 2228 / 1686 | 8 |
| `pole_sv95_anchor` | концевая/угловая с подкосом | 7.5 м | 2772 / 1860 / 1456 | 8 |
| `pole_wood` | бревно на пасынке, изоляторы на крюках | 8.4 м | 3286 / … | 4 |
| `lamp_post_steel` | граненая мачта, две «кобры» | 9.4 м | 1782 / 826 / 542 | 0 |

- Корень — на земле в центре стойки. Линия проводов идёт вдоль Y Blender (в Godot/three — вдоль −Z…+Z),
  траверсы — поперёк (X). Подкос у `pole_sv95_anchor` смотрит в сторону линии (−Y Blender / +Z Godot).
- **`Wire_<n>`** — узлы в желобке изоляторов: к ним цеплять провода (цепная линия, провис ~1–2 % пролёта;
  типичный пролёт 30–40 м). Номера: по ярусам сверху вниз, у СВ-95 — пара (левый/правый) на ярус.
- **`Lamp_Light_<n>`** — где ставить источник света (под стеклом). Стекло — материал `lamp_glass` со свечением
  (emissive): ночью усилить, днём выключить.
- `_godot.glb` — с коллизиями `*-convcolonly`; `_web.glb` — без них, meshopt. Валидатор: 0 ошибок, 0 предупреждений.
- Текстуры — `props/metal_kit`: бетон стойки, бревно, ржавый уголок, оцинковка; фарфор и стекло — без текстур.

Пересборка: `python ../metal_kit/gen_metal_kit.py` → `blender -b --factory-startup --python build_poles.py`
→ `node validate_poles.js`.
