# Складной квадрокоптер

В стиле потребительских складных дронов (по фото пользователя), без логотипов и надписей производителя.
Натуральный размер: 0.18 × 0.25 × 0.08 м без винтов, винты Ø 0.183 м (7.2″).

- `drone` — LOD0, 8456 треуг.; `drone_lod1` — 2124 треуг.; `_godot` (с коллизией-коробкой) и `_web` (meshopt).
- Нос — в +Y Blender = **−Z Godot / three** (стандартное «вперёд»). Начало координат — на земле, дрон стоит на ножках.
- **Узлы для анимации:**
  - `Prop_FL`, `Prop_FR`, `Prop_RL`, `Prop_RR` — винты, крутить вокруг своей оси Y (Godot/three; в Blender Z).
    FL и RR — против часовой стрелки при взгляде сверху, FR и RL — по часовой. В полёте ~150 об/с; для глаза
    лучше подменять на размытый диск или крутить ~20–30 об/с.
  - `Gimbal` — подвес камеры, наклон вокруг своей X (0…−90° — вниз).
- Передние винты выше задних на 16 мм (круги перекрываются, как у оригинала).
- Материалы без текстур: серый пластик, тёмный пластик/металл, чёрное стекло датчиков, линза;
  навигационные огни `led_red` (левый передний) и `led_green` (правый передний) светятся.
- Валидатор: 0 ошибок, 0 предупреждений.

## Разведывательный (военный стиль) — `drone_recon`

Строгий гранёный корпус (матовый тёмно-оливковый), карбоновые лучи X-схемы, винты 12″ (Ø 0.30 м), высокие
посадочные ноги, шар-турель под носом (камера + тепловизор), GPS-«шайба», откинутые антенны-лопатки, строб,
направляющие для подвески, датчики препятствий спереди и по бокам.
- Размер: база по диагонали моторов 0.50 м, корпус 0.33 × 0.14 м, высота на ногах 0.2 м.
- 3 LOD: `drone_recon` — 8508 треуг., AO 1024; `drone_recon_lod1` — 2860, AO 512; `drone_recon_lod2` — 996,
  без мелочей (антенны, направляющие, датчики, огни) — дальний план. `_godot` / `_web`.
- **UV:** у всех LOD — общий атлас без перекрытий на корпус, турель и винты (Smart UV Project по всем сразу).
- **AO** запечено (Cycles, радиус 12 см) в текстуру и вшито в цвет: glTF `baseColorFactor` (цвет материала) ×
  `baseColorTexture` (AO) — видно в любом движке. Пеклось в 2 прохода: корпус без винтов (крутящиеся винты не
  дают ложной тени на лучах), затем винты. Исходники: `textures/drone_recon_ao_lod0.png`, `_lod1.png`.
- Узлы: `Prop_FL/FR/RL/RR` (как у гражданского), **`Turret`** — шар-турель: рыскание вокруг своей Y (Godot),
  наклон вокруг X.

Пересборка: `blender -b --factory-startup --python build_drone.py`,
`blender -b --factory-startup --python build_drone_recon.py` → `node validate_drone.js`.
