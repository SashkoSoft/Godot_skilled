# Бортовой камень БР 100.30.15 (ГОСТ 6665-91) — модульная бровка тротуара

Камень 1000 × 300 × 150 мм, плоский скос со стороны дороги, над дорогой — 0.15 м, 0.15 м в земле.
Начало координат — **лицо камня на уровне дороги в начале куска**; кусок идёт вдоль +X, тротуар — в +Y
Blender (**−Z в Godot/three**), дорога — в −Y. Шаг укладки **1.0 м** (половинка — 0.5 м), швы 5 мм уже учтены.
Тротуар ставить вровень с верхом камня (+0.148 м), дорогу — на 0.

| Кусок | Что | Варианты текстуры |
|---|---|---|
| `curb_straight` | прямой 1 м | базовый (bare_a), `_bare_b`, `_bare_c`, `_white` (побелка), `_black` (чёрный) |
| `curb_half` | 0.5 м — подгонка длины | базовый, `_white`, `_black` |
| `curb_curve_r3` | дуга R = 3 м по лицу (19.1° на кусок; 5 кусков ≈ угол 95°), тротуар внутри поворота | базовый, `_white` |
| `curb_ramp_down` / `curb_ramp_up` | понижение к въезду и обратно (верх +0.15 → +0.03 м) | базовый |
| `curb_low` | пониженный камень въезда (верх +0.03 м) | bare_b |
| `curb_broken` | с большим сколом | bare_c, `_white` |

- Белые и чёрные камни — чередовать у переходов, остановок, въездов (как в СССР).
- Базовые bare_a/b/c — перемешивать случайно, ещё и поворачивать на ±0.5° и приподнимать на 0–1 см — «гуляющая» бровка.
- LOD: LOD0 — 238 треуг. (рёбра неровно «съедены»), `_lod1` — 28, `_lod2` — 24 (без скоса); текстуры 1024×512 / 512×256 / 256×128.
- `_godot.glb` — с коллизией `*-convcolonly` (часть над дорогой; у дуги — 3 куска), `_web.glb` — без неё, meshopt.
- Khronos glTF-validator: 0 ошибок, 0 предупреждений.

Пересборка: `python gen_curb_textures.py` → `blender -b --factory-startup --python build_curb.py` → `node validate_curb.js`.
