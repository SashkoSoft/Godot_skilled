# Советская детская площадка

Пять снарядов, каждый — свой `.glb` (корень на земле по центру; в Godot/three.js Y вверх):

| Снаряд | Размер | Треуг. LOD0 / 1 / 2 | Подвижное |
|---|---|---|---|
| `ring_climber` — лазалка с кольцами | 5.8 × 0.1 × 3.0 м | 5244 / 2196 / 1182 | — |
| `arch_ladder` — дуга-лесенка | 3.6 × 0.65 × 1.8 м | 1800 / 856 / 540 | — |
| `carousel` — карусель, 4 сиденья | Ø 2.0 × 1.0 м | 3660 / 1596 / 996 | `Carousel_Rotor` — вращать вокруг вертикальной оси |
| `swing` — качели | 2.1 × 1.4 × 2.25 м | 412 / 268 / 212 | `Swing_Seat` — точка на балке, качать вокруг X (±60°) |
| `sandbox` — песочница (некрашеные доски в 2 ряда, бортик, уголки) | 2.0 × 2.0 × 0.33 м | 194 | — |
| `gribok` — грибок (ставить в центр песочницы) | 1.6 × 1.6 × 2.5 м | 76 | — |
| `seesaw` — балансир с покрышками | 3.0 × 0.3 × 0.9 м | 4360 / 1832 / 1016 | `Seesaw_Beam` — качать вокруг оси опоры (в Blender Y, в Godot/three −Z), ±12° |

- `_godot.glb` — с коллизиями `*-convcolonly` (Godot сделает StaticBody3D). Коллизии ротора карусели и
  сиденья качелей — дочерние узлы подвижных частей и двигаются вместе с ними. `_web.glb` — без коллизий, meshopt.
- LOD: `_lod1`, `_lod2` — меньше сегментов у труб, текстуры вдвое меньше.
- Текстуры — из `props/metal_kit`: облезлая краска по трубам (7 цветов: blue, navy, yellow, red, green,
  white, rusty — под краской виден старый слой другого цвета, дальше ржавчина), крашеное и серое дерево, песок.
  У каждой трубы свой кусок текстуры — сколы не повторяются.
- Khronos glTF-validator: 0 ошибок и 0 предупреждений.

Пересборка: `python ../metal_kit/gen_metal_kit.py` → `blender -b --factory-startup --python build_playground.py`
→ `node validate_playground.js`.
