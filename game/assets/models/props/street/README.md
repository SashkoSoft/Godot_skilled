# Уличные мелочи СССР

По фото с Wikimedia Commons (контейнеры Новгорода и деревень, урна на столбе, парковая скамейка с литыми
боковинами, скамейка с бетонными боковинами, будка «ТЕЛЕФОН»).
Корень каждого — на земле по центру; Z вверх в Blender (Y вверх в Godot). «Перед» предмета — +X Blender
у скамеек (сиденье к +X), −Y Blender (= +Z Godot) у будки (дверь) и контейнера (надпись).

- **Подвижное:** `Urn_Bin` — бак урны, поворот вокруг оси X узла (опрокидывание 0…110°).
- **Стекло будки** — полупрозрачный материал (alpha blend).
- `_godot.glb` — с коллизиями `*-convcolonly`; `_web.glb` — без них, meshopt. Валидатор: 0 ошибок, 0 предупреждений.
- Текстуры: облезлая краска по листу (`props/metal_kit`: sheet_*), чугун, коричневое дерево, свои — люк,
  табличка, мытый бетон (`gen_street_textures.py`).

Пересборка: `python ../metal_kit/gen_metal_kit.py` → `python gen_street_textures.py` →
`blender -b --factory-startup --python build_street.py` → `node validate_street.js`.
