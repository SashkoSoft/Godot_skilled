# Забор ПО-2 — гладкая бетонная плита

Плита 4.0 × 2.0 × 0.16 м на двух ножках (всего 2.55 м, как у ПО-2). Начало координат — на земле по центру,
низ плиты на 0.12 м над землёй, ножки уходят на 0.43 м в землю. Ставить встык с шагом **4.0 м по X**.
В Godot/three.js (Y вверх) лицо смотрит в +Z, тыл — в −Z (стороны равноправны).

Два способа использовать:
1. **Готовые .glb** — варианты A (грязная), B (ржавая, битая), C (сырая, мох, лишайник),
   D (крашеная, облезшая) с запечённой смесью. Все по 28 треугольников; LOD — это разрешение текстур:
   LOD0 — 2048 (≈1.5 МБ), `_lod1` — 1024 (≈0.55 МБ), `_lod2` — 512 (≈0.1 МБ).
2. **Шейдер набора** `../concrete_kit` на любом из этих мешей — у каждой плиты своя смесь 12 слоёв.
   В мешах уже есть UV2 / uv1 = «координаты стены» (0..1 поперёк и снизу вверх; `wall_size = 4 × 2`).

- `_godot.glb` содержат `FenceCollision-convcolonly` (Godot сам сделает StaticBody3D). `_web.glb` — без
  коллизии, meshopt (three.js: `MeshoptDecoder`).
- Khronos glTF-validator: 0 ошибок и 0 предупреждений.

Пересборка: `python ../concrete_kit/gen_kit.py` → `python bake_fence.py` →
`blender -b --factory-startup --python build_fence.py` → `node validate_fence.js`.
