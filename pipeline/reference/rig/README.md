# Эталонный риг: `smpl_rig.glb`

Скелет, на котором договариваются роль `aimocap`, роль `houdini-assets` и движок.
Один и тот же для всех: анимации приезжают на нём, модель персонажа привязывается
к нему же.

## Что это

Скелет **SMPL**, 22 кости — ровно то, что отдаёт мокап-пайплайн
`C:\Users\Papa\Documents\AImocap` (GVHMR, SIGGRAPH Asia 2024). Файл собран из
мокап-выгрузки: анимация снята, меш выброшен, кости возвращены в позу покоя.

Замер по самому файлу (bind-поза, метры, Y вверх):

```
костей: 22, скелетов: 1, мешей: 0, анимаций: 0
кости по Y: 0.008 .. 1.464 (таз 0.913, шея 1.333)
лицом в −Z: носок стопы (z = −0.022) впереди щиколотки (z = +0.095)
левая сторона по −X: left_wrist x = −0.218
```

`head` — сустав у основания черепа, поэтому 1.464 это не рост. Рост персонажа
по коже ≈ **1.70 м**, на него и рассчитывать модель.

Оси и сторонность совпадают с конвенцией Godot (Y вверх, вперёд −Z, правая
рука по +X), ничего доворачивать не надо.

## Кости — полный список и иерархия

```
pelvis
├── left_hip → left_knee → left_ankle → left_foot
├── right_hip → right_knee → right_ankle → right_foot
└── spine1 → spine2 → spine3
    ├── neck → head
    ├── left_collar → left_shoulder → left_elbow → left_wrist
    └── right_collar → right_shoulder → right_elbow → right_wrist
```

Кистей, пальцев и лицевых костей в SMPL-22 нет. Понадобятся — это отдельный
разговор и другой скелет (SMPL-X), а не «добавлю парочку».

## Правила

- Кости **не переименовывать**, не добавлять, не удалять, позу покоя не менять.
  Godot сравнивает позы покоя при переносе анимаций между скелетами: разойдутся —
  анимация поедет.
- Масштаб в костях = 1.
- Это **не персонаж**. Персонаж — отдельная модель от `houdini-assets`,
  привязанная к этому же скелету.

## Лицензия

Скелет получен из SMPL-модели, она распространяется по своей лицензии и требует
регистрации (`https://smpl.is.tue.mpg.de`). Здесь лежат **только имена, иерархия
и поза покоя** — ни весов, ни формы тела, ни меша SMPL в файле нет. Если дойдёт
до коммерческого релиза, лицензию SMPL надо перечитать отдельно; пометка стоит
здесь, чтобы вопрос не потерялся.

`LICENSE-godot-demo-projects.md` рядом относится к прежнему тестовому ригу
(`robot_rig.glb`, MIT) и оставлен как есть.

## Прежний риг `robot_rig.glb`

Робот из официального демо Godot (`3d/platformer`, MIT), 27 костей с IK-контролами
(`r-LEGCONTROL`, `l-ARMORIENT`) и нестандартными именами (`r-thigh`, `l-forearm`),
8 готовых клипов внутри (`idle`, `walk`, `run`, `jump`, `falling`, `shooting`,
`shooting_standing`, `RESET`).

Больше не эталонный: под мокап он не годится — ретаргет SMPL-22 на 27 костей
с контролами это отдельная работа, а собственные клипы робота к игре отношения
не имеют. Файл оставлен: он удобен как заведомо рабочий образец правильного
`.glb` со скелетом и анимациями, если надо с чем-то сверить импорт.
