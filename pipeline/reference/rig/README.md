# Эталонный риг: `robot_rig.glb`

Тестовый персонаж со скелетом и готовыми анимациями. Лежит здесь, чтобы у роли
`houdini-anim` был **проверенный скелет**, на котором можно делать клипы, не гадая,
встанут ли они в движок.

## Что это

Робот из официального демо-проекта Godot (`3d/platformer`). Файл прогнан через нашу же
приёмку (`tools/asset_check/check.sh`) и импортируется в Godot 4.7 без ошибок:

```
меш: Robot — 1911 треугольников, 2 материала
габариты: 1.68 × 2.12 × 0.64 м, пивот ровно в основании (низ по Y = 0.00)
скелетов: 1
анимации: idle, walk, run, jump, falling, shooting, shooting_standing, RESET
```

## Лицензия

Демо-проекты Godot распространяются под **MIT** (полный текст — в
`LICENSE-godot-demo-projects.md` рядом). Использовать, изменять и распространять можно,
включая коммерческое использование, при сохранении уведомления об авторских правах.
Отдельной лицензии у этого файла нет — он покрывается общей.

Это **тестовый** риг для отладки пайплайна, а не персонаж игры. Персонаж игры будет свой.

## Как его использовать (роль `houdini-anim`)

1. Импортировать `robot_rig.glb` в Houdini (glTF), взять оттуда скелет.
2. Делать клипы **на этом скелете**: не переименовывать кости, не менять позу покоя,
   не добавлять и не удалять кости. Тогда результат гарантированно встанет на персонажа.
3. Отдавать по обычному правилу — `.glb` в `delivery/<task-id>/v<N>/`. Способ сдачи
   (всё в одном файле или отдельный файл с анимациями) указывается в задании.
4. Все требования к клипам — в `pipeline/ANIM_SPEC.md`, особенно раздел
   «Совместимость клипов для смешивания»: один полный шаговый цикл, одинаковая
   стартовая фаза, скорость в м/с в отчёте.

Готовые клипы робота (`walk`, `run`, `idle`) можно открыть и посмотреть, как это сделано —
они рабочие и заведомо совместимы с движком. Но **копировать их не надо**: задание всегда
говорит, что именно нужно сделать.

## Чего в этом риге нет

**Root motion.** Все клипы демо сделаны «на месте», перемещение считает код.
Поэтому режим с запечённым перемещением проверяется только на новых клипах —
это отдельный пункт в задании, когда он понадобится.
