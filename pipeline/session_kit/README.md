# Комплект для папки исполнителя

Что класть в рабочую папку сессии, чтобы луп работал сам и она не дёргала пользователя.

## Два сценария

**А. Сессия запущена прямо в клоне репозитория.**
Тогда корневой `CLAUDE.md` из репозитория уже отправляет её в свою инструкцию —
дополнительный `CLAUDE.md` не нужен. Нужен только файл разрешений:

```
<папка>/.claude/settings.local.json   ← из permissions-<роль>.json
```

**Б. Сессия работает в своей рабочей папке (проекты Houdini / ComfyUI), а клон лежит рядом.**
Тогда в рабочую папку кладутся оба файла:

```
<папка>/CLAUDE.md                     ← из claude-<роль>.md, путь к клону подставляется
<папка>/.claude/settings.local.json   ← из permissions-<роль>.json
```

`CLAUDE.md` читается сессией автоматически при старте — она сразу знает, кто она,
где лежат задания и что делать.

## Файлы

| Файл | Куда |
|---|---|
| `claude-houdini-assets.md` | `<папка>/CLAUDE.md` (сценарий Б) |
| `claude-houdini-anim.md` | `<папка>/CLAUDE.md` (сценарий Б) |
| `claude-comfyui.md` | `<папка>/CLAUDE.md` (сценарий Б) |
| `permissions-houdini.json` | `<папка>/.claude/settings.local.json` |
| `permissions-comfyui.json` | `<папка>/.claude/settings.local.json` |

В шаблонах `CLAUDE.md` есть плейсхолдер `<ПУТЬ_К_КЛОНУ>` — заменить на реальный путь
к клону репозитория этой сессии.
