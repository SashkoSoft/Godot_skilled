## 1–2. Шва нет ни в одном из двух наборов

Ваша z-оценка меряет перепад на стыке против **среднего** перепада
между соседними столбцами. У рисунка, чья граница попала на край
тайла, это даёт большое число на ровном месте: край плитки и есть
самый резкий переход в картинке, а средний перепад считается по всем
1023 столбцам, где переходов почти нет.

Проверил иначе — прямым опытом. Если поле периодично, то рендер,
посчитанный при `uv + 0.5` **без заворачивания**, обязан совпасть с
`roll(исходная, 512)`. Это проверяет саму функцию, а не картинку.

| набор | карта | v1: макс. расхождение | v2 |
|---|---|---|---|
| `floor-parquet-3` | albedo / normal / orm | **0 / 0 / 1** из 255 | 0 / 0 / 0 |
| `floor-lino-2` | albedo / normal / orm | **0 / 0 / 1** из 255 | 0 / 0 / 0 |
| `floor-parquet-2` | albedo / normal / orm | 80 / 0 / 132 | 0 / 0 / 17 |

То есть возвращённые наборы были периодичны **точно**, а принятая
ёлочка — единственная, где расхождение было. Знак вашей оценки вышел
обратным правде: −2.2 у неподходящей карты и +6.4 у безупречной.

**Тем не менее правку сделал.** Сдвинул фазу рисунка: линолеум на
(0.125, 0.0625) тайла, щитовой на (1/32, 1/32). Уложенный пол от этого
не меняется — это чистый перенос всей картинки, — но край тайла теперь
приходится на середину доски, а не на её кромку.

| набор | карта | z гор. v1 → v2 | z верт. v1 → v2 |
|---|---|---|---|
| `floor-lino-2` | albedo | **+7.4 → −2.3** | +0.7 → −1.8 |
| `floor-lino-2` | normal | +3.3 → −0.3 | **+8.1 → −0.2** |
| `floor-parquet-3` | albedo | **+6.5 → −0.5** | **+4.9 → −0.6** |
| `floor-parquet-3` | orm | **+5.2 → −0.9** | **+6.5 → −0.9** |

Все девять карт теперь ниже среднего внутреннего перепада.

Если будете мерить так же дальше — оценку стоит считать не против
среднего, а против **самого резкого внутреннего** перехода: рисунок
с крупной кромкой иначе будет краснеть всегда.

## 3. Карта id — и ошибка, которую она вскрыла

`floor_parquet_2_id_1k.png`, серые градации, **144 уровня** — ровно по
числу планок в тайле, площади 7140…7354 текселя. Записана без
цветокоррекции (`raw`), читать как data.

Собирая её, нашёл настоящую ошибку в ёлочке. Ячейки одной планки
сводились к её якорю формулой

```c
anch = horiz ? (cq.x - m, cq.y) : (cq.x, cq.y - (m - 4));   /* было */
```

Вдоль `+x` величина `m` растёт, а вдоль `+y` **убывает**, поэтому у
вертикальной планки знак должен быть плюс. С минусом четыре ячейки
одной планки получали четыре разных якоря и, значит, четыре разных
жребия: планка шла пятнами по 5 см вместо ровного тона на 20 см.
Замер на решётке: из 532 якорей **только 10** собирали по четыре
ячейки. После правки — 232 из 280 (остальные обрезаны краем окна
замера). На картинке это видно: у половины планок тон менялся
посередине без шва.

Без этой правки карта id красила бы четвертинки планок, то есть не
делала бы того, ради чего запрошена.

Заодно убрал округлённую константу: поворот на 45° и масштаб
`k·2L·√2` дают в произведении **целое 24**, и писать надо целым.
`33.9411f` давала подтексельное дрожание на границах планок по всему
полю — те самые 80 и 132 из таблицы выше.

## Отклонения от задания

1. **Ёлочку всё-таки тронул**, хотя просили не трогать. Причина —
   ошибка якоря выше: карта id без неё бессмысленна, а сама ошибка
   видна глазом. Файлы v1 на месте; если переимпорт сейчас неудобен,
   можно взять из v2 только `floor_parquet_2_id_1k.png`, но тогда
   номера планок будут расходиться с тоном на albedo.
2. **Шва в возвращённых наборах не было** — правка сделана под вашу
   проверку, а не под дефект. Числа выше.
3. **Фаза меняет файлы, но не результат укладки.** Если где-то тайл
   уже подогнан к геометрии не тайлингом, а вручную по UV, сдвиг это
   сломает — скажите, верну прежнюю фазу.
4. **Карта id только для ёлочки.** Для плитки и щитового собирается
   тем же кодом, скажете — пришлю.
5. **Уровни id перемешаны** шагом 55 по модулю 144: подряд идущие
   номера давали соседним планкам почти один серый, и разброс по тону
   получался невидимым. Перестановка взаимно однозначная, 144 уровня
   целы.
6. **Сцена сохранена как `.hiplc`** — обычный `.hip` лицензия Indie не
   пишет.
7. **Конвенция нормали импортом в движок не подтверждена**, проверено
   косвенно.
