# Запуск сессий-исполнителей

Готовые команды. Всё выполняется на этой же машине, каждая сессия — в своей папке,
общаются они только через git. Автор проекта видит все доставки, но задания и правки идут не через него:
вопросы идут в `tasks/blocked/`, а отвечает Godot-сессия.

Ключ SSH на машине уже работает (`git@github.com` пускает), отдельная настройка не нужна.

## 1. Houdini — модели, текстуры, VFX

**В терминале:**

```bash
cd /c/Users/Papa/Documents
git clone git@github.com:SashkoSoft/Godot_skilled.git houdini_assets
cd houdini_assets
git config user.name "houdini-assets"
git config user.email "prujinkin@gmail.com"
claude
```

**Первое сообщение в сессии** (без лупа — разовая проверка):

```
Ты — сессия-исполнитель роли houdini-assets в этом репозитории.
Прочитай pipeline/HOUDINI_LOOP.md — это твоя полная инструкция, действуй строго по ней.
Сейчас выполни только раздел «Что сделать в самом начале»: прочитай спеки и проверь
своё окружение (hython, экспорт .glb и .png). Заданий пока не бери.
Отчитайся: что готово, чего не хватает.
```

**Когда окружение подтверждено — включить луп:**

```
/loop 20m Прочитай pipeline/HOUDINI_LOOP.md и выполни одну итерацию цикла. Бери только задания с assignee: houdini-assets. Если своих заданий в pipeline/tasks/open/ нет — ничего не делай и молча заверши итерацию.
```

## Про интервал

20 минут — разумный старт. Задания появляются нерегулярно, а пустая итерация по инструкции
обязана быть дешёвой и молчаливой. Если работа пойдёт плотно — можно сократить до 10 минут;
если сессии подолгу простаивают — увеличить до часа. Интервал меняется перезапуском лупа.

## Если луп спотыкается о запросы разрешений

В лупе никто не нажимает «разрешить», поэтому сессия зависнет на первом же запросе.
Разрешить нужное заранее — в каждой папке исполнителя создать
`.claude/settings.local.json`:

```json
{
  "permissions": {
    "allow": [
      "Bash(git pull:*)",
      "Bash(git add:*)",
      "Bash(git commit:*)",
      "Bash(git push:*)",
      "Bash(git mv:*)",
      "Bash(git status:*)",
      "Bash(git log:*)",
      "Bash(bash pipeline/status.sh:*)"
    ]
  }
}
```

Плюс то, чем сессия реально работает: `Bash(hython:*)` для Houdini, запуск ComfyUI —
для генерации. Список можно дополнять по мере того, как выяснится, что она запрашивает.

Файл `settings.local.json` локальный и в репозиторий не попадает.

## Порядок включения

1. Поднять все три и убедиться, что каждая **читает репозиторий и видит свою инструкцию**.
2. Дождаться отчёта об окружении — до этого лупы не включать, иначе они будут падать
   на каждой итерации.
3. Включить луп сначала **одной** сессии (`houdini-anim`, у неё есть задание) и посмотреть,
   как пройдёт полный цикл: взяла → сделала → положила → закрыла → запушила.
4. Если цикл прошёл чисто — включать остальные.

## Куда смотреть за состоянием

Из Godot-сессии:

```bash

bash pipeline/status.sh                  # вся доска
bash pipeline/status.sh --for comfyui    # очередь одной роли
git log --oneline -15                    # кто что сделал
```
