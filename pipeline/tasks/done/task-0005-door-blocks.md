# task-0005 — Дверные блоки: межкомнатные и входные

> Требования к сдаче: `pipeline/ASSET_SPEC.md`

## Зачем это в игре

Сейчас в доме 91 дверной проём, и все они — дыры в стене: ни коробки, ни полотна,
ни наличника. Игрок проходит через них постоянно, это самая часто видимая деталь
интерьера после самих стен.
Дом строится из кода по поэтажному плану БТИ: восемь квартир на этаже, три этажа,
сеттинг — заброшенный жилой дом спустя годы после катастрофы, умеренная стилизация
(`docs/STYLE_GUIDE.md`). Камера изометрическая, наклон 40°, игрок видит помещение
сверху-сбоку с 10–45 метров, но подходит к предметам вплотную.

**Размеры проёмов взяты из построенной геометрии, это не пожелания, а факт:**

| | |
|---|---|
| высота этажа | 3,00 м, в свету 2,84 |
| внутренняя перегородка | 0,16 м |
| наружная стена | 0,34 м |
| межкомнатный проём | 0,80 × 2,24 м |
| входной в квартиру | 0,90 × 2,24 м |
| оконный проём | 1,70 × 1,54 м, низ на 0,85 от пола |
| проём лифта | 1,10 × 2,24 м |

## Требования

- **Что именно:** четыре объекта.
  1. `door-room` — межкомнатный блок под проём 0,80 × 2,24 в стене 0,16.
     Коробка, наличник с обеих сторон, полотно филёнчатое.
  2. `door-flat` — входная в квартиру, 0,90 × 2,24 в стене 0,16. Полотно толще,
     дерматин с обивкой гвоздиками, глазок, номер квартиры не нужен.
  3. `door-frame-only` — та же коробка без полотна: часть дверей в брошенном доме
     стоят без створок.
  4. `door-broken` — полотно, сорванное с петель: лежит или висит на одной петле.
- **Пивот:** в середине низа проёма, ось Z наружу от полотна. Полотно отдельным
  объектом с пивотом на оси петель, чтобы я мог его поворачивать.
- **Стиль:** советская квартира 70-х, крашеное дерево. Не новьё: краска
  облупилась, углы обиты.
- **Детализация:** видно вплотную. Филёнки, наличник и петли геометрией,
  мелочь — картой нормалей.
- **Бюджет:** до 1500 треугольников на блок вместе с полотном.

## Формат сдачи

Как в `ASSET_SPEC.md`. Отличия:

- полотно отдельным узлом внутри `.glb`, имя `leaf`, пивот на петлях;
- материал один на все четыре объекта, атлас 1K.
