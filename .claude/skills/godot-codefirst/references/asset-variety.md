# Разнообразие из немногих ассетов: что решает сборка, а что заказ

Сцена, собранная из кода, повторяется сильнее ручной: один и тот же материал
ложится на все стены, одна модель встаёт во все проёмы. Ниже — что с этим
делать, в порядке от дешёвого к дорогому.

## Три источника непохожести, и только один дорогой

| источник | цена | что даёт |
|---|---|---|
| поворот и отражение тайла | ноль | ×4 на каждом наборе без вертикали |
| слои: чистая база + декали | почти ноль | локальные повреждения там, где нужно |
| набор вариантов | сдача за каждый | разные рисунки, разные состояния |

Порядок работы обратный интуиции: **сначала выжать поворот и слои, и только
потом заказывать новые наборы**. Иначе очередь исполнителей забита тем, что
можно было получить строчкой кода.

## Что можно крутить, а что нельзя

Тайл поворачивается на 90/180/270 и зеркалится, если у него нет **вшитой
вертикали**:

- крутится: паркет, плитка, линолеум, бетон, потолок, штукатурка;
- не крутится: обои (полотнище вертикально), крашеная стена с панелью до пояса,
  всё с бордюром или направленным потёком.

Это должно быть сказано в задании явно — «рисунок без вертикали, обязан
тайлиться после поворота на 90°». Вшитая вертикаль там, где её не просили,
отнимает три четверти пользы от набора, и понимаешь это только на сборке.

## База чистая, износ отдельно

Локальное повреждение, вшитое в тайл, повторяется через каждый метр и читается
как узор, а не как повреждение. Поэтому:

- в базе — только **равномерное**: выцветание, затёртость, разнотон;
- пятно, скол, потёк, плесень — **декаль**, ставится в конкретное место.

Проверка одна: на укладке 4 × 4 глаз не должен находить повторяющуюся примету.

Отсюда же **два состояния** вместо пяти: `целое` и `битое`. Промежуток
набирается декалями, и это дешевле, чем три лишние сдачи.

## Вещь говорит, где она стоит

Ассет несёт смысл о своём месте, и поставить его не туда — грубее, чем
поставить некрасивый. Дверь, обитая дерматином, — входная; филёнчатая —
межкомнатная; с остеклением вверху — балконная.

**Выбирать модель по размеру — ошибка, которая обязательно выстрелит.** У нас
проём между комнатами 0.94 оказался шире входного 0.88, и правило
`if width >= 0.86: входная` поставило дерматиновую дверь внутрь квартиры.

Правильно — по соседям проёма: посмотреть, что за помещения лежат по обе
стороны, и решить по ним.

```gdscript
func _door_role(cx: float, cz: float, along_z: bool) -> DoorRole:
	var p := 0.40
	var a := _kind_at(cx - p, cz) if along_z else _kind_at(cx, cz - p)
	var b := _kind_at(cx + p, cz) if along_z else _kind_at(cx, cz + p)
	if a == "лоджия" or b == "лоджия":
		return DoorRole.BALCONY
	if a == "" or b == "":            # снаружи помещения нет — выход из квартиры
		return DoorRole.ENTRANCE
	return DoorRole.ROOM
```

Из этого же следует требование к исполнителю: **называть модели по назначению**
(`door_flat`, `door_room`), а не по размеру (`door_090`). Имя по размеру
провоцирует выбор по размеру.

## Выбор варианта должен быть устойчивым

Вариант выбирается детерминированно — от координаты или от индекса помещения,
никогда от `randi()`. Иначе дом меняется между запусками, и нельзя ни сравнить
два кадра, ни воспроизвести жалобу.

```gdscript
var seed_v := int(absf(pos.x) * 71.0 + absf(pos.z) * 131.0) % 100
```

Множители — простые числа, чтобы соседние проёмы не попадали в один класс.

## Что варьировать, а что нет

Полезно решить это один раз и записать: в панельном доме **оболочка типовая,
начинка разная**. Стены, окна, двери подъезда — по одному экземпляру достаточно.
Всё, до чего жильцы дотягивались руками, — разное: обои, пол, плитка, дверное
полотно, светильник.

Практическое следствие: наборов обоев нужно 4 на 8 квартир этажа, а плитки
санузла хватает одной — её меняли реже всего.

## Масштаб — в метрах, и это часть сдачи

Тайлящийся набор без размера тайла в метрах не встаёт вообще: материал кладётся
трипланарно, `uv1_scale = 1 / размер`. Требовать `tiles.txt` (`имя размер
описание`) и `sizes.txt` для декалей — машиночитаемо, чтобы код читал файл, а не
цифру из переписки.

Заодно это ловит ошибки плотности: паркетная планка 5 × 20 см, плитка 15 см,
полотнище обоев 53 см. Если тайл обоев 1.06 — это ровно два полотнища.
