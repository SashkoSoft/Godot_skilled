# Раскладка объектов правилами

## Устройство правила

Правило в данных, генератор в коде. Правило говорит **где** (у фасадов,
у заборов, вокруг куч, у стволов, в области, по прямоугольнику, на проезжей
части), **сколько** (число, диапазон, плотность на длину), **какое** (смесь
классов/пород с весами). Код один на все правила; новое место — новая строка
в JSON, а не новый `if` в коде.

```json
{ "near": "facades", "buildings": ["slab", "tower"],
  "density": 0.035, "piles": [3, 7], "overlap": 0.55,
  "materials": { "concrete": 0.4, "brick": 0.15, "rebar": 0.2 } }
```

## Два генератора случайности

- **Поток раскладки** (одно зерно на правило) — только положение и размер.
- **Параметры от координат** (`rng(x, z, соль)`) — порода, состояние,
  материалы, фаза. Добавление параметра не сдвигает ни одного объекта.

Проверка: число и координаты объектов до и после добавления параметра
совпадают.

## Запреты (одна функция `fits`)

- в прямоугольник дома (с допуском: кучу можно привалить к стене);
- ближе к оси дорожки, чем `полуширина + радиус объекта` — проход свободен;
- в круг перед дверью (≈ 2.5 м);
- на твёрдые площадки: парковка, спортплощадка, детская, контейнеры;
- на ствол дерева; на машину/лавку/ларёк (круг по габариту);
- на другой объект: `dist < (r1 + r2) · overlap`, где overlap < 1 — скопление,
  ≈ 1.45 — не пересекаются повёрнутые коробки;
- в исключённые зоны правила (убежище, лагерь).

## Скопления

Центр скопления — точка на периметре стены, отодвинутая наружу на
`0.5 … 2 + 0.2·H`; объекты — в круге радиусом `1.5 + 0.08·H` вокруг центра.
Число скоплений у дома = `периметр × плотность × (0.5 + H/30)`. У башни
в 12 этажей это ≈ 7 скоплений до 9 м от стены, у пятиэтажки — 5 ближе.

## Параметры для библиотеки ассетов

Если модели будут делать другие (Houdini и т. п.) — у каждого экземпляра
в данных те же ключи, что в манифесте библиотеки (`species / age / health`,
`size / materials`). Игра подбирает ближайший вариант по ключам, среди
равных — по зерну экземпляра (соседи не копии), и вписывает в габарит.
Исполнителю отдаётся таблица «сочетание → сколько штук + габариты» — по ней
он решает, сколько вариантов нужно (3 на частые, 1 на редкие).
