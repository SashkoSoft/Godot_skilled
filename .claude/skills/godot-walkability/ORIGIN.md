# Откуда скил

Собран в проекте изометрической игры на Godot 4.7 (август 2026), где типовой
этаж восьмиквартирной секции строился из кода по скану поэтажного плана БТИ.

Поводом стал вопрос пользователя «логику проверил дверей? все комнаты
доступны?». Графовая проверка отвечала «да»; физическая показала, что достижим
один пятачок перед лестницей. Всё, что в скиле, — из разбора этого расхождения.
