# Откуда этот скил и как его подключить

## Происхождение

Выжимка из сессий по проекту **Collapse** (`C:\Users\Papa\Documents\collapse\g_collapse`):
3D-хоррор в процедурном лабиринте на Godot 4.7 — WFC-генерация с деформацией
пространства, многоэтажность с лестницами, физика игрока и снарядов,
бестиарий из 6 типов ИИ-охотников, процедурный звук, скриншот-харнесс и
host-авторитарный мультиплеер на ENet. ~8600 строк GDScript, вся сцена
строится кодом, в GUI-редакторе Godot не сделано ни одного клика.

Числа (`prims` до и после, FPS) — реальные замеры на RTX 4070 Ti Super и на
ноутбуке с интегрированной графикой. Все грабли описаны потому, что на них
наступили, а не потому, что так написано в документации.

## Отношение к скилу `godot-codefirst`

Пакеты **дополняют друг друга**, ставить лучше оба:

| Тема | Где |
|---|---|
| код-первый подход, старт проекта, экспорт .exe | `godot-codefirst` |
| материалы, шейдеры, пост-эффекты, небо, частицы | `godot-codefirst/visuals-3d.md` |
| MultiMesh, батчинг, LOD, общий порядок оптимизации | `godot-codefirst/performance.md` |
| звук: пул плееров, синтез, зацикливание | `godot-codefirst/audio.md` |
| грабли GDScript 4 и переезд с Godot 3 | `godot-codefirst/gdscript-gotchas.md` |
| **скриншот-харнесс и самопроверка визуала** | здесь |
| **физика: контроллер, RigidBody, коллизия из меша** | здесь |
| **корректность процедурной геометрии, winding, швы** | здесь |
| **тени/прозрачность: обвалы кадра, режим «слабый ПК»** | здесь |
| **мультиплеер ENet, host-авторитет, чат и голос** | здесь |

Если два текста расходятся — верь тому, где есть замер или воспроизводимый
симптом, и перепроверь на своём проекте.

## Подключение

Скил подхватывается, если папка `godot-selfcheck-3d/` лежит в одном из:

- `C:\Users\<user>\.claude\skills\` — доступен во всех проектах;
- `<проект>\.claude\skills\` — только в этом проекте.

```powershell
Copy-Item -Recurse "C:\Users\Papa\Documents\godot_skilled\External_sessions_skills\godot-selfcheck-3d" `
  "$env:USERPROFILE\.claude\skills\"
```

Новая сессия видит скил по описанию из frontmatter и читает `references/*.md`
по мере надобности — сам `SKILL.md` намеренно короткий.

## Что тут НЕ описано

- 2D-пайплайн (TileMap, спрайты), анимации и скелеты, импорт `.glb`,
  `NavigationAgent3D` — в Collapse ничего этого не использовалось
  (навигация — свой BFS по клеткам, модели — только процедурные меши).
- Экспорт под Web/Android/Linux: собиралась только Windows-сборка
  (single-file `.exe` с `embed_pck`).
- Выделенный сервер, матчмейкинг, релей: мультиплеер — только прямой IP в
  локальной сети, хост = один из игроков.

Если новая сессия заходит на эту территорию — пусть проверяет по документации
Godot 4 (`Documents/godot_skilled/docs/godot-docs`, там же демо-проекты), а не
достраивает по аналогии с этим текстом.
