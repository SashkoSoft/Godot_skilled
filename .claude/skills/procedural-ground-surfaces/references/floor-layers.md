# Пол квартала: слои по правилам + тайловые наборы

Как устроено в `web/src/floor.js` (данные — `ground` в `game/district.json`).

## Три части

1. **Карта весов** (шаг 0.5 м, до 8 слоёв в двух RGBA). Считается ПРАВИЛАМИ от
   данных квартала, не рисуется руками: `{layer, near, dist, weight}`, где near —
   `paths | doors | facades | piles | trees | fences | objects:<виды> |
   areas:<виды> | buildings:<виды>`. Вес спадает от края источника до нуля на `dist`.
   Особые: `facades` — досягаемость `dist + perDamage·damage` (разрушенный дом
   осыпается шире); `trees` — `dist` в радиусах кроны. Почва — остаток
   (`1 − max(остальных)`, не меньше 0.15). Так пол получается у ЛЮБОГО
   квартала, включая сгенерированный.
2. **Наборы** одного формата, сложенные в два `DataArrayTexture`:
   A = albedo.rgb + height, B = normal.xy + roughness + AO. Один отсчёт на слой.
3. **Смешивание по высоте**: оценка слоя = вес + (height − 0.5)·height_cm·0.12 +
   рваная кромка шума. Сверху тот, у кого выше; переход 0.12. Поэтому камни
   торчат из земли, опад ложится в низины — край рваный, а не градиент.

Трава вытесняется слоями (`ground.grass`: доля на слой) — карта травы берёт
`grassCut` отсюда, травинки гаснут на тропах и крошке сами.

## Слои без правил: дёрн

Слой с `"grass": k` берёт вес от карты травы (`k · густота`), канал карты
ему не нужен; `"select": [канал шума, от, до]` делит площадь между вариантами
(свежий / выгоревший / мох) пятнами. Почва (`"rest": true`) уступает дёрну:
под газоном дёрн, в проплешинах почва. Выгоревшего — не больше трети площади,
иначе газон читается песком.

## Накладки — стопки предметов (главный инструмент стыков)

`ground.overlays`: листья, камешки, травинки, куски. Маска RGBA: R — порядок
предмета в стопке (порог `R > 1 − плотность` оставляет верхние предметы
ЦЕЛИКОМ), B — светотень (0.5 нейтраль), A — высота. Плотность = канал правил
(`{"overlay": id, ...}`) + `grass · густота` + `ambient` пятнами шума.
- `"under": "turf"` — под газоном (стелющаяся трава, ветошь), остальные — сверху
  всего, иначе под травой их не видно;
- стыки: правило с `"edge": true` меряет от КРОМКИ в обе стороны — камешки
  рассыпаны по самому стыку дорожки и земли, целыми, а не градиентом;
- накладки «сверху» ложатся и на твёрдые покрытия (`hardify` на материалах
  дорожек, проездов, асфальта) — стык сшивается с обеих сторон;
- каждая стопка — два отсчёта, второй повёрнут на произвольный угол (тайл
  бесшовный ⇒ поворот тоже), побеждает предмет выше в стопке; порог каждой —
  по половине плотности, иначе покрытие растёт. Производные — до ветвлений,
  свои у каждого отсчёта (`textureGrad`), иначе мипы рвутся по краю предмета.
- Маски читать через WebGL без премультипликации (`rawPixels`): canvas 2D
  умножает цвет на альфу, а альфа тут — высота, и R портится по краям.

## Однородные покрытия: шестиугольное расслоение

Песок, утоптанная земля — мало деталей, повтор тайла читается сразу, второй
повёрнутый отсчёт пятнами не спасает. `"antitile": "hex"`: треугольная сетка
(ячейка ≈ тайл), в каждой вершине тайл со своим поворотом и сдвигом, три
отсчёта барицентрически с усилением по высоте (`w³ · (0.25 + h)⁴`). Три
отсчёта на слой — только вблизи и только помеченным слоям. `textureGrad` с
повёрнутыми производными, нормаль каждого отсчёта — обратно в мир.

## Ленты переходов (стык покрытия с землёй)

Лента: U тайлится вдоль края (4 м), V ровно 1 м поперёк, 0 — покрытие.
Шейдеру нужна карта кромки (0.25 м): знаковое расстояние до ОБЪЕДИНЕНИЯ всех
дорожек (минимум по отрезкам — иначе на перекрёстке край одной дорожки внутри
другой рисуется стыком), направление вдоль края одной ориентации (иначе U
переворачивается), тип стыка. Тротуары — только дворовая сторона. Лента
работает с ОБЕИХ сторон: на земле (отколотые куски асфальта) и на покрытии
(выбоины с землёй, трещины вдоль кромки, трава языками на плитку); её канал
крошки — плотность накладки камешков.

## Гранж и сырость

Маска RGBA 8 м: на полу — сырость (темнее, глаже); на твёрдых — грязь,
сырость, мох по швам только там, где грязно, трещины вблизи. Вариант слоя
(`"from": "<слой>"`) делит канал своего слоя: сухая/сырая утоптанная земля по
сырости гранжа — рисунок у вариантов общий, камни на переходе не прыгают.

## Чёткие маски — только в смеси

Клеточный шум (многоугольники, прямые рёбра), трещины и швы мха из гранжа
сами по себе — узнаваемый узор на полу. Не резать порогом по одной такой
маске: выборку искажать другим шумом (~0.05 тайла), при выборе варианта
подмешивать шум и грязь, трещины и мох давать пятнами (смесь шума и грязи),
а не по всей площади.

## Формат набора (ground-pack) — требовать от поставщика

- `<name>_{albedo,normal,orm,height}_1k.png`, бесшовные;
- albedo sRGB **без** запечённого света, AO, теней;
- normal OpenGL (+Y); ORM = R AO, G roughness, B metal (0);
- height линейный, 0 — низ, 1 — верх, распределение как в жизни;
- `tile.txt`: `tile_m`, **`height_cm`** (реальный перепад — без него высоты
  разных наборов несравнимы и смешивание по высоте врёт), `albedo_mean`;
- без одиночных узнаваемых деталей на тайл.

## Ловушки D3D (Chrome на Windows) — программный GL их НЕ ловит

Проверять шейдер надо под ANGLE D3D11 (`--use-angle=d3d11 --enable-gpu`), не
только под swiftshader: у того лимиты шире, и сломанное у пользователя у нас
«работает».
- **Не больше 16 текстур на шейдер** (MAX_TEXTURE_IMAGE_UNITS). Считать вместе
  с картой теней. Много однотипных карт — в `DataArrayTexture` (одна выборка).
  Симптом: «нет земли», в консоли `texture image units count exceeds`.
- **Выборка с авто-производными (`texture`, `dFdx`) в цикле с continue/break
  не собирается** (X4014). Производные — до цикла, в цикле `textureGrad`/`textureLod`.
- `v[i]` по переменному i — эмуляция ветвлениями и предупреждения; брать канал
  `dot(v, vec4(equal(ivec4(i), ivec4(0,1,2,3))))`.
- Литералы в конструкторах только дробные: `vec3(0, 1, 0)` → неоднозначность,
  программа «собрана», но не рисует.
- `renderer.debug.onShaderError` вызывается только при провале линковки; причина —
  в `getProgramInfoLog`, а не в первой строке журнала шейдера (там WARNING).

## Ловушки

- Строки картинки при сборке массива переворачивать (как flipY), иначе
  зелёный канал нормали смотрит не туда.
- sRGB только у массива A; высота в альфе от этого не страдает.
- Нет набора — заглушка из почвы с оттенком (`stand_in`), в консоли помечено
  «ЗАГЛУШКА». Не выдавать заглушку за готовый слой.
- Отладка: `#ground=debug` — слои условными цветами; сначала проверять
  раскладку, потом вид.
- Память: 6 слоёв × 2 массива × 1k ≈ 64 МБ с мипами; на телефоне `res 512`
  (`#gtex=512`) — вчетверо меньше.
